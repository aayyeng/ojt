# Auto-commit and push after edits

After completing and verifying code or documentation changes in this repository:
1. Stage the modified project files (never stage `data/`, `.venv/`, `__pycache__/`, or `needed files/`).
2. Commit with a clear, concise message describing the change.
3. Push to `origin main` (`https://github.com/aayyeng/ojt.git`) automatically without waiting to be asked.
